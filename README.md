🎯 Vision

To develop a customizable Linux environment with its own identity, tools, and user experience.

🛠️ Current Features

- Custom LIBRAX terminal branding
- System information display
- Interactive command-not-found installation prompts
- Debian package management
- Android deployment through Termux and PRoot-Distro

📍 Project Status

Early Development — Version 0.1

LIBRAX HOME currently runs as a Debian-based environment inside Termux using PRoot-Distro. It is not yet a standalone Linux distribution.
